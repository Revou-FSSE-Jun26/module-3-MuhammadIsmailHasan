# Bootcamp Module 3 — Muhammad Ismail Hasan

Module 3 assignments: building web pages with HTML, CSS (Tailwind), and TypeScript.

## Repository contents

| Folder | Description |
| --- | --- |
| `profile-page/` | Personal profile page (home, about, skills, work, contact) with dark mode. |
| `product-catalog/` | Indonesian product catalog with search, filters, sorting, and a cart. See its [README](product-catalog/README.md). |
| `docs/` | UI mockups and design documents used as reference. |

## Running the projects

**Profile page:** open `profile-page/index.html` in a browser.

**Product catalog:**

```bash
cd product-catalog
npm install
npm run dev
```

Then open `product-catalog/src/index.html` in a browser.

## Tech

HTML, Tailwind CSS 3, TypeScript.
